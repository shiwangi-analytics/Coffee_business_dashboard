# ☕ Coffee Shop Sales Analysis Dashboard

## 📊 Project Overview
This project is an interactive Coffee Shop Sales Analysis Dashboard created using Microsoft Excel. It helps in analyzing sales performance, customer footfall, and product trends to generate meaningful business insights.

## 🎯 Objectives
- Analyze overall sales performance
- Identify peak hours and busy days
- Find top-selling products
- Understand customer purchasing behavior

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Data Cleaning Techniques

## 📈 Key Metrics
- Total Sales: $698,812.33  
- Total Footfall: 149,116  
- Average Bill per Person: 4.69  
- Average Orders per Person: 1.44  

## 📊 Dashboard Features
- ⏰ Hourly Order Trend Analysis  
- 📅 Weekday vs Weekend Sales  
- 📦 Category-wise Sales Distribution  
- 🏆 Top 5 Products by Sales  
- 📍 Store Location Analysis  
- 🎛️ Interactive Filters (Day & Month)
